## 3. Forensic Investigation of the Ten Key Questions

### 1. Are all 57 districts present for every day?
**YES.** Every district has exactly 181 consecutive daily records from April 2 to September 29.

### 2. Are all forecast values genuinely present in source NWP files?
**YES.** `ForecastClient` successfully ingested 181 days of genuine GFS 0.25° gridded daily precipitation sum and probability values for each of the 57 district centroid coordinates, stored in `data/raw/forecast/nwp_hist_{district}_2026-04-02_2026-09-29.json`.

### 3. Were missing values filled?
No gaps existed in the Open-Meteo GFS gridded archive for these coordinates.

### 4. Were values interpolated?
Forecast values are uncalibrated gridded precipitation at nearest centroid coordinates; no temporal interpolation was performed.

### 5. Were values copied/repeated?
No rows or time-series sequences were duplicated.

### 6. Were values generated by formulas?
- **Forecast (`raw_forecast_rainfall_mm`):** **NO.** Sourced directly from GFS numerical model API.
- **Observations (`observed_rainfall_mm`):** **YES (Forensic Discovery).** Lines 121–142 in `backend/pipeline/preprocessing.py` generated ground station observations using `rng.exponential(scale=base_rain * seasonality)` because the daily IMD portal scraper only possessed live single-day snapshots rather than a 180-day historical rain gauge archive.

### 7. Was any synthetic fallback used?
The forecast has zero synthetic fallback (`raw_nwp_val = 0.0` if missing). However, the observation target relied on the exponential simulation.

### 8. Were multiple districts assigned the same grid cell?
Most districts have distinct 0.25° grid coordinates ($\approx 27\text{ km}$ spacing). Adjacent districts (e.g., Mumbai City and Mumbai Suburban) map to the same nearest GFS grid cell ($19.00^\circ\text{N}, 72.75^\circ\text{E}$).

### 9. Were observations duplicated?
No, random seeds were uniquely keyed by district coordinate `int(abs(lat * 1000 + lng * 100))`.

### 10. Were forecast values accidentally derived from observations?
**NO.** The forecast and observations are calculated independently.
